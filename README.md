Playwright TypeScript Practice 🎭

This repository contains my hands-on practice with Playwright and TypeScript. With professional experience in Selenium, I am expanding my automation skills by learning Playwright, a modern framework increasingly used for fast and reliable end-to-end testing.

📚 Topics Covered:

* Playwright setup and configuration
* Writing and organizing tests
* Locators and assertions
* InputBoxAssertions and dropdowns 
* RadioButtons and checkboxes
* KeyBoardActions

🛠️ Tech Stack:

* Playwright
* TypeScript
* Node.js
* VS Code
* Git and Github

⚙️ Getting Started:

Follow these steps to run the project locally.

Prerequisites:
1. Node.js installed
2. npm installed
3. Visual Studio Code or any preferred code editor
4. Basic knowledge of TypeScript is helpful

Step 1: Clone the repository
        
        git clone https://github.com/NehaKhapekar/playwright-typescript-practice.git

Step 2: Navigate to the project
       
        cd playwright-typescript-practice

Step 3: Install dependencies
       
        npm install

Step 4: Install Playwright browsers
      
        npx playwright install

Step 5: Run Playwright tests
       
        npx playwright test

Step 6: View the test report
       
        npx playwright show-report


🎯 Purpose:

This is a learning and practice repository, not a complete automation framework. I am using it to build my understanding of Playwright cript and gradually learn the concepts and practices involved in designing a maintainable test automation framework.
